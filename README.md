# 图片二维码合成工具

纯前端、本地运行的图片二维码合成工具。把二维码图片（动态 / 固定）合成到底图上，支持位置、缩放、旋转、四边裁剪与拖拽，并可批量导出为 ZIP。

## 特性

- **纯本地**：所有图片处理都在浏览器内完成，不上传任何服务器。
- **零依赖**：单个 `index.html`，无需联网、无需安装任何库或运行时，双击即用。
- **动态 / 固定二维码**：可导入多张动态二维码循环合成，也可固定一张常驻底图。
- **精准定位**：X / Y / 缩放 / 旋转 数值微调 + 画布直接拖拽 + 四边裁剪手柄，旋转态下裁剪用局部坐标系，对边保持固定。
- **批量导出**：按导入顺序批量合成并打包为 ZIP，文件名带时间戳，导出后缀与实际编码格式对齐。
- **健壮性**：内置底图尺寸 / 像素上限校验、导出期间编辑锁、裁剪边界收敛、拖拽出窗防粘滞、加载竞态令牌等。

## 使用方法

1. 双击 `index.html`（或拖入浏览器）打开。
2. 上传底图，再导入一张或多张二维码图片。
3. 通过右侧面板或直接在画布上拖拽、缩放、旋转、裁剪，摆好位置。
4. 点击「批量导出」，生成 `二维码合成结果-YYYYMMDD-HHMMSS.zip`。

## 技术说明

- 原生 JavaScript + Canvas，无第三方库，无构建步骤。
- ZIP 打包为内置的纯 JS 实现（无 JSZip 等外部依赖）。
- 完全离线可用，适合分发到不同电脑使用。
